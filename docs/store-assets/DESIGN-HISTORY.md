# Design history archive

Exploratory artwork and historical visual reviews live in the Obsidian vault:

`/Users/rico/projects/ai-work-notes/projects/mesozoic-protocol/assets/README.md`

[Open the collection](/Users/rico/projects/ai-work-notes/projects/mesozoic-protocol/assets/README.md)

The collection includes base layouts, world-map iterations, terrain, lighting, water, combat effects, and store artwork experiments. The store archive preserves A/B/C, A2/A3, rejected A4 exports, and A5 crop/alignment proofs under `assets/design-history/2026-09-30/store-artwork/`. Captions and the SHA-256 manifest record provenance; source images are unchanged.

Binary archive media is ignored by vault Git and needs the normal vault backup. It is not shipped with this game or available from a fresh Git clone. No Git history was rewritten.

Approved A5 masters, selected upload exports, prompts, fonts/licenses, recipes, and current manifests remain in this repository. `catalog.json` and the assembly scripts do not depend on the vault. Live rendering documentation remains under `docs/rendering/`; dated copies in the vault are historical references.
