# Natural forest props

Repository-owned procedural meshes generated by `node scripts/generate-natural-props.mjs`.
Four tree variants and three shrub variants use tapered branching trunks and folded,
individually oriented leaves. These are geometry models, not photographic scans.
Three grass variants use thin, tapered, bent blades with subdued vertex colours.
No third-party model or texture inputs. Leaf and bark colours are vertex/material data.

The runtime keeps its instanced renderer, measured footprint, hit discs and removal flow.
Tree height is normalized by the existing TREE_TARGET_HEIGHT contract. Keep the four
variant slots for saved campaign compatibility. Forest stone generation is disabled at
its existing layer index; it does not create hidden collision/placement blockers.
